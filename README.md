# GHL Bangladesh — homepage redesign

Static redesign of the ghlbangladesh.com homepage. All original text, images and video are kept.

| Version | Path | Style |
|---|---|---|
| Home v2 (current, also served at `/`) | `v2/index.html` | HighLevel brand look — Poppins, navy-to-blue hero, cyan/yellow buttons |
| Home v1 | `v1/index.html` | First redesign — Plus Jakarta Sans, dark editorial look |

Shared assets live in `images/community/`.

Open locally through any static server, e.g. `python3 -m http.server 8080`.
